# Lumi Direct Maintenance Operator Policy v1

Remote maintenance is scoped, authenticated, auditable, and revocable. The relay is transport, not authority. Guardian remains the independent install and recovery gate. Never wake the screen, play sound, vibrate, speak, or present a full-screen prompt during unattended maintenance. If Android requires physical approval, stage safely and return WAITING_FOR_USER_APPROVAL. Every request must end with either verifiable success or a diagnostic failure record. Never claim an update succeeded unless post-update certification passed.
