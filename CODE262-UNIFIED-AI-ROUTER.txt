6. GitHub workflow version checks were stale at Code260; they now verify Code262 / 4.0.15-unified-ai-router-r1.

Security / behavior preserved:
- API keys remain in SecretStore and are never written into diagnostics or prompts.
- Local-first/offline continuity remains intact.
- Mutating maintenance tools still require the existing authorization layer and Guardian/update checks.
