WHAT IS INCLUDED

- Guardian/Fast Brain launch certification path.
- Signed-update enforcement for AI/remote maintenance. Manual user-selected local ZIPs retain the existing checksum/whitelist path.

IMPORTANT SECURITY BOUNDARIES
- No remote shell.
- No arbitrary file access.
- No Guardian bypass.
- Remote/AI maintenance downloads must remain HTTPS.
- AI/remote maintenance packages require a trusted Lumi manifest signature.
- Mutating maintenance requires admin enrollment + unlocked device + explicit current approval.
- Captured voice is not yet used as biometric proof of identity.
- API keys/tokens are not put into prompts, Memory Vault entries, tool outputs, or portable backup data.

BEFORE YOU UNINSTALL THE CURRENT LUMI
Do NOT uninstall an existing Lumi until any local data you want to keep has been exported/preserved. Android normally removes app-private data when an app is uninstalled.

BUILD / INSTALL
1. Build/install APK Factory v2.6.1 and prove it can complete a build/download on your phone.
2. Feed THIS Lumi 1.0 source ZIP to APK Factory v2.6.1.
3. APK Factory uploads/builds the source. Its generic assembleDebug call is intercepted by the Lumi root/app Gradle tasks: Guardian builds first, is embedded into Lumi, then only the primary Lumi APK remains for APK Factory artifact selection.
4. Install Lumi-1.0-FULL-LAUNCH-Code247.apk from the resulting artifact.
5. Launch Lumi and allow the embedded Guardian companion installation when prompted.
6. Complete Lumi administrator setup before allowing maintenance writes.
7. Run Guardian -> Lumi 1.0 certification and verify the real Fast Brain probe returns LUMI_READY.
8. Verify Memory Vault continuity / restore any portable backup if needed.
9. Reboot/relaunch and verify Lumi still recalls persistent context.
10. Prove one signed modular maintenance update end-to-end. After that, APK Factory should become fallback infrastructure rather than the normal update path.

SOURCE GREEN VS DEVICE GREEN
The included audit can certify source/package integrity. It cannot certify Android runtime behavior without the APK Factory/GitHub build and the actual phone/Guardian checks above.
